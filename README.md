# Kalkulator Dua Dimensi

Satu aplikasi dengan menu untuk persegi, persegi panjang, segitiga, trapesium,
layang-layang, jajar genjang, belah ketupat, lingkaran, segi lima beraturan,
dan segi enam beraturan. Setiap kalkulator menampilkan luas, keliling,
rumus, dan substitusi ukuran.

Pilih bangun di halaman depan, isi ukuran dalam sentimeter, lalu tekan
**Hitung luas dan keliling**. Gunakan **Kosongkan** untuk menghapus input
dan **Semua bangun datar** untuk kembali ke menu.

Lihat [persyaratan build](../README.md). Dari folder proyek, jalankan:

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

APK tersedia di `app/build/outputs/apk/debug/app-debug.apk`.
